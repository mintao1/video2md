# 工作流重构：Dify → LangGraph，video2md + gpu_router 双服务部署 lcode-4c

## 总体拓扑（docker-compose 单栈，内网互联）
```
┌─ lcode-4c (4C/7.5G) ────────────────────────────┐
│  video2md 容器 :8790(发布) ──内网── gpu_router 容器 :9700(不发布,无认证) │
│     │ LangGraph 内嵌编排               │ 选举 Colab/Kaggle/ZeroGPU/国内云 │
│     └─ 本地: download/frames/note      └─ 远程: whisper/OCR/clips        │
│  volumes: vault(笔记) / data(checkpoint+state) / gpu-router-logs        │
└──────────────────────────────────────────────────┘
```
Syncthing 把 vault 同步回 Mac 本地 Obsidian。

## 选型结论（已重判，维持）
LangGraph 内嵌（不引 langchain）+ FastAPI/uvicorn + SqliteSaver checkpointer（替代 runs.json/jobs.json，含 checkpoint 裁剪）；httpx 直连 Kimi-K3；prompt 用 `{{var}}` 自定义替换（避开 JSON 示例花括号与 str.format 冲突）；串行逐 entry 回环；本地 `langgraph dev` 白嫖 Studio 调试，生产不用 LangGraph Server。

## 开放风险（部署时验证，不阻塞）
- **服务器出口代理**：无代理则 Colab/Kaggle/HF/Modal 全灭，只剩国内云 provider；需要你确认 lcode-4c 上有什么代理可用
- **YouTube 源**：同理需代理，否则 video2md 仅支持国内平台
- colab-cli OAuth token 过期需在 Mac 上刷新后重新注入容器
