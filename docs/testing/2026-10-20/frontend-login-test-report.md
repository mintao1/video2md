## 关键观察

1. 登录页可正常渲染，页面结构和主要文案存在。
2. OAuth 入口使用后端地址；在当前 fixture 环境中，Google 凭据为空，后端返回明确的 `auth_error`，前端将错误显示在登录页。
3. 当前环境无法验证真实 Google 授权、回调换票、真实 ID token 登录后的页面访问；需要配置 Google OAuth 凭据或使用项目已有的集成回跳 token。

## 未测/阻塞

## 建议

在测试环境注入 Google OAuth client 配置，或提供一个仅限测试环境的固定 token 回跳入口，再继续执行登录成功后的全链路验收。当前前端构建和 API 集成门禁均已通过。

## 新增缺陷

### T-01 [P2] 新建转换允许空链接提交但无反馈（已修复）

- 复现：任务页 → “更多导入方式” → “清空” → “立即开始转换排队”。
- 修复：链接为空时阻止提交，并在输入区显示“请输入视频或音频链接”字段错误。
- 影响：用户无法判断提交是否生效，可能重复点击；真实后端请求是否被发出需进一步检查。
- 验证：`npm run build` 与 `npm run test:integration` 均通过（22/22）。
