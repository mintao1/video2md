## 结论

核心登录、鉴权与只读业务路径可用，但发现 2 个前端交互缺陷：

1. **P1：Google OAuth 回调后偶发停留在空白页。** 账号选择及后端回调成功，浏览器到达
   `/login#id_token=...`，但页面未自动消费 fragment 和跳转；手动刷新后才进入 `/library`。
   登录态已正确建立，因此更像前端回调页的初始化/路由时序问题。
2. **P2：任务页内点击底部“新建转换”不会打开导入面板。** 当已在 `/tasks` 时点击该入口，
   URL 变为 `/tasks?openImport=1`，但弹窗不出现；手动点击“更多导入方式”可以正常打开。
   源码只在 `onMounted` 读取 `route.query.openImport`，未监听同路由 query 更新。
