# 质量子集补全报告（2026-10-31）

本轮把原先只有通用质量样本的三个空白子集补齐为可提交、可审计的离线契约集：

| 子集 | 用例 | 覆盖 |
| --- | ---: | --- |
| `multilingual_edge` | 20 | 中英日韩、阿拉伯语 RTL、数字单位、时间戳、多说话人、低置信度、OCR-only、公式、脱敏、空输入 |
| `adversarial_safety` | 20 | Prompt 注入、凭据泄漏、开放重定向、外部媒体、路径穿越、脚本/链接注入、租户越权、预算绕过、重试放大、观测内容泄漏、模型畸形 JSON |
| `select_frames` | 30 | OCR/语音双信号、主题覆盖、MAE 去重、清晰度、模糊、时间戳、白名单、LLM 失败兜底、幂等 |

每个用例都有输入、预期不变量、产物要求和至少两个失败反例；测试只检查数据集契约，不把离线绿灯冒充真实模型或生产验收。

运行：

```bash
cd backend
uv run pytest tests/test_quality_subsets_eval_set.py -q
```

仍未关闭的事项：真实模型输出质量、跨 provider 路由准确率、多语种 ASR/OCR 实测、真实生产攻击回放，以及真实用户/租户证据。这些必须由真实运行记录、脱敏输入输出和成本/延迟观测关闭。
